# life-simulation

A clean-room, from-scratch re-implementation of the idea behind **[dominikvytisk/life-simulation](https://github.com/dominikvytisk/life-simulation)** by [@dominikvytisk](https://github.com/dominikvytisk). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
